# Yaotian Zhang's Academic Homepage

Source for [dandelionskyy.github.io](https://dandelionskyy.github.io), an English academic homepage focused on robotic perception, state estimation, SLAM, sensor fusion, and autonomous navigation.

## Editing

- Main content: `_pages/about.md`
- Profile and site metadata: `_config.yml`
- Navigation: `_data/navigation.yml`
- Visual styles: `assets/css/main.scss`
- CV: `files/Yaotian-Zhang-CV.pdf`
- Project images: `images/`

GitHub Pages builds this repository with Jekyll. To preview locally, install Ruby and Bundler, run `bundle install`, then run `bundle exec jekyll serve`.

The site is based on [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) and retains its original license.
